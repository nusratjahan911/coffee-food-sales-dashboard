# ☕ Coffee & Food Sales Performance Dashboard

## 📊 Project Overview

This project presents an interactive **Coffee & Food Sales Performance Dashboard** developed using Microsoft Excel. The dashboard provides insights into sales performance, revenue, profit, product categories, and customer transaction trends.

The main objective is to transform raw sales data into meaningful business insights through data analysis and interactive visualizations.

## 🎯 Project Objectives

- Analyze total sales and revenue performance.
- Track total transactions and quantity sold.
- Compare revenue and profit across product categories.
- Identify sales trends by day, month, and year.
- Analyze revenue performance across different cities.
- Build an interactive dashboard for business decision-making.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Power Query
- PivotTables
- PivotCharts
- Excel Formulas
- Slicers
- Data Visualization

## 📈 Dashboard Features

### 1. Key Performance Indicators (KPIs)
- Total Transactions
- Total Quantity Sold
- Total Revenue
- Total Profit

### 2. Sales Analysis
- Revenue by Product Category
- Transactions by Product Category
- Transactions by Day of the Week
- Yearly Revenue Analysis
- Monthly Revenue Trends
- Revenue by City
- Revenue vs. Profit by Product Category

### 3. Interactive Features
- City Slicer
- Product Category Slicer
- Year Slicer
- Interactive PivotCharts
